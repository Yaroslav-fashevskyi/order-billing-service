# Release v1.1.0

## Added

- Додано окремий тариф доставки для Києва — 80 грн.
- Додано параметр tax_rate для передачі ставки податку.

## Changed

- Збільшено вартість доставки за кілограм з 12 до 15 грн.
- Виконано рефакторинг коду та перехід до Data Coupling.

## Breaking Changes

- Змінено параметри функцій розрахунку.
- Видалено глобальну змінну GLOBAL_TAX_RATE.
- Видалено параметр mode_flag.
- Функцію process_invoice замінено на дві окремі функції.
